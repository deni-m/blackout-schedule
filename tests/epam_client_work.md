# EPAM - Client Work test scenario

Status: Ready

Purpose: Validate navigation to Client Work area from the Services menu.

Preconditions:
- Internet connection is available
- Browser supports modern features (Chrome/Chromium)

Steps:
1. Navigate to https://www.epam.com/
2. If a cookie consent banner appears, click "Accept All" or equivalent to close the banner
3. In the header, select the "Services" menu item (if not present, try "What We Do")
4. Click the link or button labeled "Explore Our Client Work"
5. Verify that text "Client Work" is visible on the resulting page

Expected Result:
- The Client Work page opens and the text "Client Work" is visible
